# Smart Pen | 智能阅读助手 🖊️

这是一个简易的分词学习网页，用以将整段中文文本拆解为独立的词汇，并提供即时的拼音和英文释义。

## 功能

* **智能分词 (Smart Segmentation):** 自动将长句子切分为有意义的词组。
* **词库 (Big Dictionary):** 整合了 **CC-CEDICT** 开源词典，并加入高频词优化 (Priority Patch)，针对 70+ 个容易产生歧义的常用字、连接词（如：可、那儿、着）进行了人工释义校对，确保解释贴近日常用法。
* **实时发音 (Text-to-Speech):** 点击词语即可聆听标准普通话读音。
* **图片识别辅助 (OCR Workflow):** 适配 iPad/iPhone 的“实况文本”功能，拍照即可提取文字进行分析。尚未在安卓系统上尝试使用。

## 🚀 如何使用 (How to Use)

1.  **导入内容:** 点击“打开相机”拍摄文本，或从相册选取图片。
2.  **提取文字:** * 在网页预览图中长按文字。
    * 点击 **"显示文本 (Show Text)"**，然后选择 **"拷贝 (Copy)"**。
3.  **开始分析:** 点击蓝色 **"分析内容 (Analyze)"** 按钮，网页将自动生成词语卡片。
4.  **学习词汇:** 点击生成的词语卡片，查看详细的拼音和英文定义。
